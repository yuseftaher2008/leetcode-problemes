# LeetCode Problems

A collection of algorithm and data structure solutions in TypeScript.

## Problems

| File | Problem | Difficulty |
|------|---------|------------|
| `towSums.ts` | Two Sum | Easy |
| `sumOfTowNums.ts` | Two Sum (variant) | Easy |
| `addTowNumbers.ts` | Add Two Numbers | Medium |
| `palindromeNumber.ts` | Palindrome Number | Easy |
| `probleme.ts` | First Missing Positive | Hard |
| `longestSubstringWithoutRepatingChar.ts` | Longest Substring Without Repeating Characters | Medium |

## Running

```bash
# Run a specific solution
npx tsx towSums.ts

# Or compile and run
npx tsc towSums.ts && node towSums.js
```
